## Grand Theft Auto: Harboursville

Playable Harboursville sandbox in [gta-sydney-psyco](gta-sydney-psyco/). The map is Sydney geography under a fictional city name. It does not run Grand-V or GTA3Web and it does not ship proprietary GTA assets.

Setup, controls, and the Quay Loop are in [gta-sydney-psyco/README.md](gta-sydney-psyco/README.md). Map licences and the Grand-V inspection notes are in [gta-sydney-psyco/ATTRIBUTION.md](gta-sydney-psyco/ATTRIBUTION.md).

Browser games in this repository.

## GTA: Sydney Psyco

Playable Sydney Harbour driving sandbox in [gta-sydney-psyco](gta-sydney-psyco/). It is an original WebGL game. It does not run Grand-V and it does not ship proprietary GTA assets.

Setup, controls, and the Quay Loop are in [gta-sydney-psyco/README.md](gta-sydney-psyco/README.md). Map licences and the Grand-V inspection notes are in [gta-sydney-psyco/ATTRIBUTION.md](gta-sydney-psyco/ATTRIBUTION.md).
